## 1. M1 – 최종 과제와 작업 계획

**제목:** M1_tarea final y plan de trabajo para el proyecto „La Feria del Libro“

### 최종 과제 (Tarea final)

Vamos a leer en parejas diferentes álbumes ilustrados en clase. Después de la lectura, los álbumes se presentarán a los demás en una Feria del Libro. Cada pareja crea un puesto en el que presenta su libro.

> **한국어:** 짝과 함께 그림책을 읽고, 책 박람회에서 다른 친구들에게 소개합니다. 각 팀이 부스를 만듭니다.

### 읽는 동안 (Durante la lectura)

#### 1. 읽기 전략 사용하기
7학년 프로젝트 „Imagina animales“에서 배운 전략을 사용합니다. **M5** 자료가 도움이 됩니다.

#### 2. 메모하기 (발표용 요점)

| 번호 | 스페인어 | 한국어 |
| :--- | :--- | :--- |
| 1 | Nombrad el título, el/la autor/a, el/la ilustrador/a del álbum, la editorial y el año de publicación. | 제목, 작가, 일러스트레이터, 출판사, 출간 연도를 말하세요. |
| 2 | Explicad el o los tema(s) del álbum y la trama. | 주제와 줄거리를 설명하세요. |

| 4 | Comentad el grupo destinatario del álbum. | 이 책의 대상 독자에 대해 말하세요. |
| 5 | Expresad una opinión personal sobre el álbum. | 책에 대한 개인 의견을 말하세요. |

짝이 학급(또는 온라인) 앞에서 발표합니다. 두 사람이 **균형 있게** 말해야 합니다.

## 3. 발표용 문장 도움

(부스·발표용 문장 틀 – 스페인어 / 한국어)

### 1. 개인 평가 – 삽화

| 스페인어 | 한국어 |
| :--- | :--- |
| Esta ilustración es mi / nuestra ilustración favorita porque… | 이 삽화가 나/우리의 제일 좋아하는 삽화인 이유는… |

| Las imágenes me / nos parecen… bonitas / feas / aburridas / interesantes / divertidas / curiosas… | 그림이 나/우리에게 … 예뻐 / 못생겨 / 지루해 / 흥미로워 / 재미있어 / 특이하게 보여요. |

**위치 / 전치사:**

| 스페인어 | 한국어 | 스페인어 | 한국어 |

| a la derecha | 오른쪽에 | a la izquierda | 왼쪽에 |

## 4. M7 – 그림책 소개하는 방법

박람회 발표를 돕는 표입니다. 측면(B)은 책과 관심에 따라 달라질 수 있고, 문장(C)은 제안입니다.

### 작가와 일러스트레이터

| 항목 | 스페인어 | 한국어 |
| :--- | :--- | :--- |
| 이름 | El autor / La autora se llama… | 작가 이름은… |
| 출생지 | El autor / La autora es de… / vive en… | 작가는 … 출신입니다 / …에 삽니다 |
| 생일 | Su fecha de nacimiento es… / nació el… | 생일은… / …에 태어났습니다 |
| 다른 책 / 상 | publicar / ilustrar un libro; recibir un premio | 책을 출간하다 / 그림을 그리다; 문학상을 받다 |

### 책과 주제

| 항목 | 스페인어 | 한국어 |
| :--- | :--- | :--- |
| 제목 | El libro se llama / el título es… | 책 제목은… |
| 출간일 | El libro se publicó en… / es del año… | 책은 …년에 출간되었습니다 |
| 주제 | El libro trata de… | 이 책은 …에 관한 이야기입니다 |

### 줄거리 (현재형으로!)

| 항목 | 스페인어 | 한국어 |
| :--- | :--- | :--- |
| 주인공 | El / La protagonista es… / Los protagonistas son… | 주인공은… / 주인공들은… |
| 줄거리 | Él / Ella hace / dice / quiere + 동사원형 | 그/그녀는 …한다 / 말한다 / …하고 싶어 한다 |

**구조화 표현:** primero / al principio · entonces · después · al final · por eso · porque

### 그림 / 삽화

| 항목 | 스페인어 | 한국어 |
| :--- | :--- | :--- |
| 양 | El libro tiene muchas / pocas imágenes. | 책에 그림이 많다 / 적다. |
| 스타일 | dibujos a lápiz, collages, acuarelas, realista, detallado, surrealista, en color, en blanco y negro | 연필화, 콜라주, 수채화, 사실적, 세밀한, 초현실적, 컬러, 흑백 |
| 역할 | Las imágenes ilustran / contradicen / complementan el texto. | 그림이 글을 설명한다 / 글과 반대된다 / 글을 보완한다. |

## 5. 우리 책 – 손글씨 메모 (M7)

**La caja de las palabras** (말의 상자)

| | |
| :--- | :--- |
| **작가** | Mar Benegas (스페인 / 발렌시아, 1975.07.11생) |
| **상** | Premio Cervantes Chico (시) |
| **일러스트** | Eva Vázquez (마드리드, 1970) — *TV 시리즈 오프닝 등* |
| **연도** | 2014 |
| **주제** | 뜻을 모르는 단어들을 이해하고 싶어 하는 소녀 |
| **주인공** | Ari (소녀); 부모님도 등장 |
| **줄거리** | 단어를 상자에 모아 보관한다 |
| **삽화** | 많다 · 컬러 · 글을 설명한다 |

**작성 예문:**

- El autor / La autora se llama **Mar Benegas**.  
  → 작가 이름은 **Mar Benegas**입니다.
- El autor / La autora es de **España / Valencia**.  
  → 작가는 **스페인 / 발렌시아** 출신입니다.
- Nació el **11.07.1975**.  
  → **1975년 7월 11일**에 태어났습니다.
- El libro se llama / el título es **La caja de las palabras**.  
  → 책 제목은 **La caja de las palabras**입니다.
- El libro se publicó en **2014**.  
  → **2014년**에 출간되었습니다.
- El libro trata de **una chica que quiere entender palabras que no sabe**.  
  → **모르는 단어의 뜻을 알고 싶어 하는 소녀**에 관한 이야기입니다.
- La protagonista es **Ari**; los protagonistas son **Ari y sus padres**.  
  → 주인공은 **Ari**이고, 주인공들은 **Ari와 부모님**입니다.
- Ella quiere **coleccionar palabras en una caja y guardarlas**.  
  → 그녀는 **단어를 상자에 모아 보관하고** 싶어 합니다.
- El libro tiene **muchas** imágenes **en color**. Las imágenes **ilustran** el texto.  
  → 책에 **컬러** 그림이 **많다**. 그림이 글을 **설명한다**.

## 6. M9 – 박람회용 개인 질문지

### 활동

부스에서 전문가들이 책을 소개합니다. 방문객으로서도 질문을 해야 합니다. 이 질문지로 미리 준비하세요.

1. 관심 있는 주제(a–f)를 고른다.
2. 전문가에게 질문 **총 12개**를 만든다. 발표마다 최소 **2개**.
3. 개인 질문을 표에 적는다.
4. 책 박람회를 방문할 때 이 질문지를 사용한다.

### 질문 주제

| | 주제 | 도움 / 팁 |
| :--- | :--- | :--- |
| **a** | ¿Te interesa la historia? (이야기에 관심 있어?) | 인물, 문제, 결말 등 더 자세히 물어보기 |
| **b** | ¿Te interesan las ilustraciones? (삽화에 관심 있어?) | 더 많은 그림 보여 달라 하기, 하나 설명 듣기, 제일 좋아하는 삽화; 그림이 읽기에 도움이 됐는지 |
| **c** | ¿Te interesa el nivel de español? (필요한 스페인어 수준에 관심 있어?) | 아주 어려운/쉬운 예; 책 속 새 어휘·문법 |
| **d** | ¿Te interesa el autor? (작가에 관심 있어?) | 생일, 다른 책, 받은 상 |
| **e** | ¿Te interesa el proceso de trabajo? (작업 과정에 관심 있어?) | 읽기 프로젝트에서 어떻게 일했는지, 기간, 어려움, 쉬운/힘든 점 |
| **f** | ¿Otros aspectos que te interesan? (다른 관심사?) | 자유 질문 |
