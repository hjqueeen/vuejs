1. Quadratwurzeln und Zahlbereiche

1.1 Definition der Quadratwurzel

Die Quadratwurzel \(\sqrt{a}\) (mit \(a \ge 0\)) ist die nichtnegative Zahl \(x\), für die gilt: \(x^2 = a\).

Also: \(\sqrt{a} = x \Leftrightarrow x \ge 0\) und \(x^2 = a\).

Warum ist \(\sqrt{-9}\) in \(\mathbb{R}\) nicht definiert?

Es gibt keine reelle Zahl \(x\) mit \(x^2 = -9\), weil das Quadrat einer reellen Zahl nie negativ ist.

Deshalb ist \(\sqrt{-9}\) in der Menge der reellen Zahlen nicht definiert.

1.2 Wurzeln im Kopf berechnen (Dezimalzahlen, Brüche)

Vorgehen: Dezimalzahl oder Bruch so umschreiben, dass man bekannte Quadratzahlen erkennt.

Beispiel: \(\sqrt{0{,}0144}\)

\[ \sqrt{0{,}0144} = \sqrt{\dfrac{144}{10000}} = \dfrac{\sqrt{144}}{\sqrt{10000}} = \dfrac{12}{100} = 0{,}12 \]

Beispiel: \(\sqrt{\dfrac{49}{225}}\)

\[ \sqrt{\dfrac{49}{225}} = \dfrac{\sqrt{49}}{\sqrt{225}} = \dfrac{7}{15} \]

Regel: \(\sqrt{\dfrac{a}{b}} = \dfrac{\sqrt{a}}{\sqrt{b}}\) (für \(a,b \ge 0\), \(b \neq 0\))

1.3 Abschätzen zwischen zwei natürlichen Zahlen

Vorgehen: Die nächsten Quadratzahlen suchen.

Beispiel: \(\sqrt{20}\)

  • \(4^2 = 16\), \(5^2 = 25\)
  • \(16 < 20 < 25\) ⇒ \(4 < \sqrt{20} < 5\)

Formulierung:

\(\sqrt{20}\) liegt zwischen den natürlichen Zahlen 4 und 5, weil \(4^2 = 16 < 20 < 25 = 5^2\).

Weiter mit dem Heron-Verfahren (bessere Näherung)

Mit dem Abschätzen weiß man nur das Intervall \(4 < \sqrt{20} < 5\). Mit dem Heron-Verfahren kann man daraus eine genauere Näherung berechnen.

Idee: Man sucht eine Zahl \(x\), für die \(x^2 \approx a\) gilt (hier \(a = 20\)).

Formel:

\[ x_{n+1} = \dfrac{1}{2}\left(x_n + \dfrac{a}{x_n}\right) \]

\(x_n\) ist der aktuelle Schätzwert, \(\dfrac{a}{x_n}\) die zweite Seitenlänge eines Rechtecks mit Fläche \(a\). Der Mittelwert wird der neue, bessere Schätzwert.

Schritt für Schritt:

  1. Startwert \(x_0\) wählen (z. B. die untere natürliche Zahl aus dem Abschätzen: \(x_0 = 4\)).
  2. \(\dfrac{a}{x_0}\) berechnen.
  3. Mittelwert bilden: \(x_1 = \dfrac{1}{2}\left(x_0 + \dfrac{a}{x_0}\right)\).
  4. Mit \(x_1\) denselben Schritt wiederholen → \(x_2\), \(x_3\), …
  5. Die Werte nähern sich schnell \(\sqrt{a}\) an.

Geometrisch: Rechteck mit Seiten \(x_0\) und \(\dfrac{a}{x_0}\) (Fläche \(a\)) → Mittelwert als neue Seite → Rechtecke werden „quadratischer“ → Quadrat mit Seite \(\sqrt{a}\).

Aufgabe: \(\sqrt{20}\) mit dem Heron-Verfahren berechnen

Berechne eine Näherung für \(\sqrt{20}\) mit dem Heron-Verfahren.

  1. Schätze zuerst ab, zwischen welchen beiden natürlichen Zahlen \(\sqrt{20}\) liegt.
  2. Wähle den Startwert \(x_0 = 4\).
  3. Berechne \(x_1\) und \(x_2\) mit der Formel \(\displaystyle x_{n+1} = \dfrac{1}{2}\left(x_n + \dfrac{20}{x_n}\right)\).
  4. Stelle die Rechnung in einer Tabelle dar.
  5. Gib die Näherung auf drei Nachkommastellen an.
Lösung

a) Abschätzen

  • \(4^2 = 16\), \(5^2 = 25\)
  • \(16 < 20 < 25\) ⇒ \(4 < \sqrt{20} < 5\)

b)–d) Heron-Rechnung mit \(a = 20\), \(x_0 = 4\):

\[ x_1 = \dfrac{1}{2}\left(4 + \dfrac{20}{4}\right) = \dfrac{1}{2}(4+5) = \dfrac{9}{2} = 4{,}5 \]
\[ x_2 = \dfrac{1}{2}\left(4{,}5 + \dfrac{20}{4{,}5}\right) = \dfrac{1}{2}\left(4{,}5 + \dfrac{40}{9}\right) = \dfrac{1}{2}\left(\dfrac{81}{18} + \dfrac{80}{18}\right) = \dfrac{1}{2}\cdot\dfrac{161}{18} = \dfrac{161}{36} \approx 4{,}472 \]
\(n\) \(x_n\) \(\dfrac{20}{x_n}\) \(x_{n+1}=\dfrac{1}{2}\left(x_n+\dfrac{20}{x_n}\right)\)
0 4 5 4,5
1 4,5 \(\dfrac{40}{9}\approx 4{,}444\) \(\dfrac{161}{36}\approx 4{,}472\)
2 ≈4,472 ≈4,472 ≈4,472

e) Ergebnis

\(\sqrt{20} \approx 4{,}472\) (auf drei Nachkommastellen).

Probe: \(4{,}472^2 \approx 19{,}999\) ≈ 20.

Halbierungsverfahren

Beim Halbierungsverfahren startet man mit dem Intervall aus dem Abschätzen und halbiert es immer wieder. Der Mittelwert entscheidet, welche Hälfte behalten wird.

Schritt für Schritt:

  1. Startintervall \([u; o]\) mit \(u^2 < a < o^2\) wählen.
  2. Mittelwert \(m = \dfrac{u+o}{2}\) berechnen.
  3. Wenn \(m^2 < a\), neues Intervall \([m; o]\); sonst \([u; m]\).
  4. Wiederholen, bis das Intervall eng genug ist.

Aufgabe: \(\sqrt{20}\) mit dem Halbierungsverfahren berechnen

Berechne eine Näherung für \(\sqrt{20}\) mit dem Halbierungsverfahren.

  1. Starte mit dem Intervall \([4; 5]\).
  2. Führe mindestens 4 Halbierungsschritte durch.
  3. Stelle die Rechnung in einer Tabelle dar.
  4. Gib ein Intervall an, in dem \(\sqrt{20}\) liegt, und eine Näherung auf zwei Nachkommastellen.
Lösung

Start: \(4^2 = 16 < 20 < 25 = 5^2\) ⇒ Intervall \([4; 5]\).

Rechnungen (Mittelwerte):

\[ m_0 = \dfrac{4+5}{2} = 4{,}5,\quad 4{,}5^2 = 20{,}25 > 20 \Rightarrow [4; 4{,}5] \]
\[ m_1 = \dfrac{4+4{,}5}{2} = 4{,}25,\quad 4{,}25^2 = 18{,}0625 < 20 \Rightarrow [4{,}25; 4{,}5] \]
\[ m_2 = \dfrac{4{,}25+4{,}5}{2} = 4{,}375,\quad 4{,}375^2 = 19{,}140625 < 20 \Rightarrow [4{,}375; 4{,}5] \]
\[ m_3 = \dfrac{4{,}375+4{,}5}{2} = 4{,}4375,\quad 4{,}4375^2 = 19{,}69140625 < 20 \Rightarrow [4{,}4375; 4{,}5] \]
\[ m_4 = \dfrac{4{,}4375+4{,}5}{2} = 4{,}46875,\quad 4{,}46875^2 \approx 19{,}970 < 20 \Rightarrow [4{,}46875; 4{,}5] \]
Schritt \(u\) \(o\) \(m=\dfrac{u+o}{2}\) \(m^2\) Vergleich mit 20 neues Intervall
0 4 5 4,5 20,25 \(> 20\) \([4; 4{,}5]\)
1 4 4,5 4,25 18,0625 \(< 20\) \([4{,}25; 4{,}5]\)
2 4,25 4,5 4,375 19,140625 \(< 20\) \([4{,}375; 4{,}5]\)
3 4,375 4,5 4,4375 19,69140625 \(< 20\) \([4{,}4375; 4{,}5]\)
4 4,4375 4,5 4,46875 ≈19,970 \(< 20\) \([4{,}46875; 4{,}5]\)

Ergebnis

Nach 4 Schritten gilt: \(4{,}46875 < \sqrt{20} < 4{,}5\).

Näherung (z. B. Mittelwert): \(\sqrt{20} \approx 4{,}48\) (auf zwei Nachkommastellen).

Vergleich: Halbierung nähert sich Schritt für Schritt an; Heron liefert meist schneller eine gute Näherung (\(4{,}472\)).

Intervallschachtelung

Bei einer Intervallschachtelung erzeugt man eine Folge von Intervallen \(I_0 \supset I_1 \supset I_2 \supset \ldots\), die immer kleiner werden und \(\sqrt{a}\) jeweils enthalten. Mit dem Halbierungsverfahren stellt man eine solche Schachtelung her.

Wichtig für die Klassenarbeit:

  • Jedes Intervall enthält \(\sqrt{a}\).
  • Die Intervalle liegen ineinander (Schachtelung).
  • Die Intervalllänge geht gegen 0 → die Einschließung wird beliebig genau.

Aufgabe: \(\sqrt{20}\) durch Intervallschachtelung annähern

Nähern Sie \(\sqrt{20}\) durch eine Intervallschachtelung an.

  1. Geben Sie ein Startintervall \(I_0\) an und begründen Sie es.
  2. Bilden Sie durch Halbierung die Intervalle \(I_1\), \(I_2\), \(I_3\) und \(I_4\).
  3. Schreiben Sie die Schachtelung \(I_0 \supset I_1 \supset I_2 \supset I_3 \supset I_4\) auf.
  4. Geben Sie an, in welchem Intervall \(\sqrt{20}\) nach 4 Schritten liegt.
Lösung

a) Startintervall

\[ I_0 = [4; 5],\quad\text{denn}\quad 4^2 = 16 < 20 < 25 = 5^2 \]

Also gilt \(\sqrt{20} \in I_0\).

b) Halbierungsschritte

Intervall \(u\) \(o\) \(m=\dfrac{u+o}{2}\) \(m^2\) Entscheidung nächstes Intervall
\(I_0\) 4 5 4,5 20,25 \(m^2 > 20\) \(I_1=[4; 4{,}5]\)
\(I_1\) 4 4,5 4,25 18,0625 \(m^2 < 20\) \(I_2=[4{,}25; 4{,}5]\)
\(I_2\) 4,25 4,5 4,375 19,140625 \(m^2 < 20\) \(I_3=[4{,}375; 4{,}5]\)
\(I_3\) 4,375 4,5 4,4375 19,69140625 \(m^2 < 20\) \(I_4=[4{,}4375; 4{,}5]\)
\(I_4\) 4,4375 4,5 4,46875 ≈19,970 \(m^2 < 20\) \(I_5=[4{,}46875; 4{,}5]\)

c) Schachtelung

\[ I_0 \supset I_1 \supset I_2 \supset I_3 \supset I_4 \]
\[ [4; 5] \supset [4; 4{,}5] \supset [4{,}25; 4{,}5] \supset [4{,}375; 4{,}5] \supset [4{,}4375; 4{,}5] \]

In jedem Intervall liegt \(\sqrt{20}\). Die Länge wird jeweils halbiert:

\[ |I_0|=1,\quad |I_1|=0{,}5,\quad |I_2|=0{,}25,\quad |I_3|=0{,}125,\quad |I_4|=0{,}0625 \]

d) Ergebnis

Nach 4 Schritten: \(\sqrt{20} \in I_4 = [4{,}4375; 4{,}5]\).

Also: \(4{,}4375 < \sqrt{20} < 4{,}5\).

Näherung: \(\sqrt{20} \approx 4{,}47\) (z. B. Mittelwert von \(I_4\)).

1.4 Warum gilt \(\sqrt{a^2} = |a|\)?

\(\sqrt{a^2}\) ist definitionsgemäß die nichtnegative Zahl, deren Quadrat \(a^2\) ist.

Das ist genau der Betrag \(|a|\).

Beispiel: \(\sqrt{(-3)^2} = \sqrt{9} = 3 = |-3|\), nicht \(-3\).

2. Irrationale Zahlen

2.1 \(\sqrt{2}\) geometrisch darstellen

  1. Einheitsquadrat mit Seitenlänge 1 zeichnen.
  2. Diagonale mit Pythagoras: \(d^2 = 1^2 + 1^2 = 2\) ⇒ \(d = \sqrt{2}\).
  3. Mit dem Zirkel die Länge der Diagonale auf die Zahlengerade übertragen.

2.2 Indirekter Beweis: \(\sqrt{2}\) ist irrational

Annahme: \(\sqrt{2}\) sei rational.

Dann gibt es teilerfremde ganze Zahlen \(p,q\) mit \(q \neq 0\) und \(\sqrt{2} = \dfrac{p}{q}\).

Quadrieren: \(2 = \dfrac{p^2}{q^2}\) ⇒ \(p^2 = 2q^2\).

Also ist \(p^2\) gerade ⇒ \(p\) ist gerade, also \(p = 2k\).

Einsetzen: \((2k)^2 = 2q^2\) ⇒ \(4k^2 = 2q^2\) ⇒ \(q^2 = 2k^2\).

Also ist auch \(q\) gerade.

Widerspruch: \(p\) und \(q\) haben den gemeinsamen Teiler 2, sind aber teilerfremd.

Die Annahme ist falsch.

Folgerung: \(\sqrt{2}\) ist irrational.

Übertragung: Dieselbe Beweisidee gilt z. B. für \(\sqrt{3}\), \(\sqrt{5}\) oder \(\sqrt{p}\) (\(p\) Primzahl).

3. Näherungsverfahren

3.1 Intervallschachtelung

Ziel: \(\sqrt{a}\) durch immer engere Intervalle annähern.

Vorgehen:

  1. Startintervall: \(u_0^2 < a < o_0^2\).
  2. Mittelwert \(m = \dfrac{u+o}{2}\) berechnen.
  3. Wenn \(m^2 < a\), setze \(u := m\); sonst \(o := m\).
  4. Wiederholen, bis die gewünschte Genauigkeit erreicht ist.

3.3 Heron-Verfahren geometrisch (Rechtecke)

Man beginnt mit einem Rechteck der Fläche \(a\) (Seiten \(x_0\) und \(\frac{a}{x_0}\)).

Als neue Seitenlänge nimmt man den Mittelwert der beiden Seiten.

Die Rechtecke werden immer „quadratischer“.

Im Grenzfall entsteht ein Quadrat mit Seitenlänge \(\sqrt{a}\) und Fläche \(a\).

4. Rechnen mit Wurzeln

4.1 Wurzelgesetze

GesetzFormelHinweis
Produkt\(\sqrt{a}\cdot\sqrt{b}=\sqrt{a\cdot b}\)\(a,b \ge 0\)
Quotient\(\dfrac{\sqrt{a}}{\sqrt{b}}=\sqrt{\dfrac{a}{b}}\)\(a \ge 0\), \(b > 0\)
Summe / Differenz\(\sqrt{a}+\sqrt{b} \neq \sqrt{a+b}\)kein entsprechendes Gesetz

Gegenbeispiel: \(\sqrt{9}+\sqrt{16}=3+4=7\), aber \(\sqrt{9+16}=\sqrt{25}=5\).

4.2 Terme vereinfachen (partielles Wurzelziehen)

Vorgehen: Quadratfaktoren herausziehen.

\[\sqrt{50} = \sqrt{25\cdot 2} = 5\sqrt{2}\]
\[\sqrt{72} = \sqrt{36\cdot 2} = 6\sqrt{2}\]
\[3\sqrt{18} - \sqrt{8} = 3\cdot 3\sqrt{2} - 2\sqrt{2} = 9\sqrt{2}-2\sqrt{2}=7\sqrt{2}\]

4.3 Nenner rationalisieren

Einfacher Fall: \(\dfrac{1}{\sqrt{a}} = \dfrac{\sqrt{a}}{a}\)

\[\dfrac{5}{\sqrt{3}} = \dfrac{5\sqrt{3}}{3}\]

Mit 3. binomischer Formel (Nenner \(a+\sqrt{b}\)):

\[ \dfrac{1}{3+\sqrt{2}} \cdot \dfrac{3-\sqrt{2}}{3-\sqrt{2}} = \dfrac{3-\sqrt{2}}{9-2} = \dfrac{3-\sqrt{2}}{7} \]

Grund: \((a+\sqrt{b})(a-\sqrt{b}) = a^2 - b\) → Wurzel im Nenner verschwindet.

5. Gleichungen

5.1 Definitionsmenge

Regel: Der Radikand muss \(\ge 0\) sein.

Beispiel: \(T(x)=\sqrt{2x-6}\)

\[ 2x-6 \ge 0 \Rightarrow x \ge 3 \Rightarrow D = \{x \in \mathbb{R} \mid x \ge 3\} \]

Bei mehreren Wurzeln: Bedingungen für jeden Radikanden aufstellen und schneiden.

5.2 Wurzelgleichungen und Scheinlösungen

Vorgehen:

  1. Definitionsmenge bestimmen.
  2. Wurzel isolieren.
  3. Beide Seiten quadrieren (kann Scheinlösungen erzeugen!).
  4. Entstandene Gleichung lösen.
  5. Probe: Kandidaten in die Ausgangsgleichung und in \(D\) einsetzen. Unpassende Werte sind Scheinlösungen.

Beispiel: \(\sqrt{x+3} = x-1\)

  • \(D\): \(x+3 \ge 0\) und \(x-1 \ge 0\) ⇒ \(x \ge 1\)
  • Quadrieren: \(x+3 = (x-1)^2 = x^2-2x+1\)
  • Gleichung lösen, danach unbedingt Probe machen
  • Werte außerhalb von \(D\) oder falsch in der Ausgangsgleichung verwerfen

Merksatz:

Beim Quadrieren können Scheinlösungen entstehen. Deshalb muss jede Lösung durch Einsetzen in die Ausgangsgleichung überprüft werden.

Checkliste vor der Klassenarbeit

  • \(\sqrt{-a}\) ist in \(\mathbb{R}\) nicht definiert (\(a>0\))
  • \(\sqrt{a^2}=|a|\)
  • Zahlen richtig zuordnen: \(\mathbb{N}\subset\mathbb{Z}\subset\mathbb{Q}\subset\mathbb{R}\)
  • \(\sqrt{2}\) geometrisch und indirekter Beweis
  • Intervallschachtelung / Heron mit Tabelle
  • Produkt- und Quotientengesetz gelten; Summe/Differenz nicht
  • Nenner rationalisieren (3. Binom)
  • Wurzelgleichung: \(D\) → quadrieren → Probe
