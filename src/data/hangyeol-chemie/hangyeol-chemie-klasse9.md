## 1. Basen – Definition und Dissoziation

**Datum:** 11.11.2024 · **Blatt:** Basen – Informationsblatt / Übungen

### 1.1 Definition

Basen sind Stoffe, die in wässriger Lösung in negativ geladene Hydroxid-Ionen (\(OH^-\)) und positiv geladene Ionen (meist Metall-Ionen) zerfallen. Dieser Vorgang heißt **Dissoziation der Basen**. Die entstehenden Lösungen nennt man **alkalische Lösungen** oder **Laugen**.

### 1.2 Allgemeine Formel

\[
\text{Base} + \text{Wasser} \rightarrow \text{Baserest-Ion} + \text{Hydroxid-Ion} + \text{Wasser}
\]

**Beispiel – Natriumhydroxid:**

| Form | Gleichung |
| :--- | :--- |
| Wortgleichung | Natriumhydroxid + Wasser → Natrium-Ion + Hydroxid-Ion + Wasser |
| Formel | \(\mathrm{NaOH} + \mathrm{H_2O} \rightarrow \mathrm{Na^+} + \mathrm{OH^-} + \mathrm{H_2O}\) |
| Kurzschreibweise | \(\mathrm{NaOH} \xrightarrow{\mathrm{H_2O}} \mathrm{Na^+} + \mathrm{OH^-}\) |

### 1.3 Regeln zu Ladung und Ionen

- Die **positive Ladung** des Baserest-Ions entspricht der **Hauptgruppennummer** im Periodensystem.
- Die **Anzahl der Hydroxid-Ionen** entspricht der positiven Ladung.
- Schreibweise: \((\mathrm{OH})_x\) ist richtig (zeigt \(x\) Sauerstoff- und Wasserstoff-Atome); \(\mathrm{OH}_x\) ist falsch (würde nur \(x\) H-Atome bedeuten).
- **Ausnahme Nebengruppenelemente:** Die Ladung wird mit **römischen Ziffern** in Klammern angegeben.

**Beispiele:**

| Stoff | Dissoziation |
| :--- | :--- |
| Calciumhydroxid (2. HG) | \(\mathrm{Ca(OH)_2} \rightarrow \mathrm{Ca^{2+}} + 2\,\mathrm{OH^-}\) |
| Eisen(III)hydroxid | \(\mathrm{Fe(OH)_3} \rightarrow \mathrm{Fe^{3+}} + 3\,\mathrm{OH^-}\) |

### 1.4 Übung – Dissoziation

**a)** Aluminiumhydroxid

\[
\mathrm{Al(OH)_3} \rightarrow \mathrm{Al^{3+}} + 3\,\mathrm{OH^-}
\]

**b)** Nickel(II)hydroxid

\[
\mathrm{Ni(OH)_2} \rightarrow \mathrm{Ni^{2+}} + 2\,\mathrm{OH^-}
\]

## 4. Herstellung 1: Metall + Wasser

### 4.1 Allgemeine Formel

Basismetalle (1. Hauptgruppe / Alkalimetalle) + Wasser:

\[
\text{Metall} + \text{Wasser} \rightarrow \text{Metallhydroxid} + \text{Wasserstoff (g)}
\]

### 4.2 Beispiel: Natrium + Wasser

| Form | Gleichung |
| :--- | :--- |
| Wortgleichung | Natrium + Wasser reagiert zu Natriumhydroxid + Wasserstoff |
| Formel (unausgeglichen) | \(\mathrm{Na} + \mathrm{H_2O} \rightarrow \mathrm{NaOH} + \mathrm{H_2}\) |
| **Ausgleichen!** | \(2\,\mathrm{Na} + 2\,\mathrm{H_2O} \rightarrow 2\,\mathrm{NaOH} + \mathrm{H_2}\) |

### 4.3 Erklärung zum Ausgleichen

- Wasserstoff (\(H_2\)) ist ein Molekül, weil er bei Raumtemperatur ein Gas ist und kein Edelgas.
- Links: in \(\mathrm{H_2O}\) stehen 2 H-Atome; rechts: 1 H in \(\mathrm{NaOH}\) + 2 H in \(\mathrm{H_2}\) = 3 H → unausgeglichen.
- Mit \(2\,\mathrm{H_2O}\) entstehen \(2\,\mathrm{NaOH}\); dafür braucht man links \(2\,\mathrm{Na}\).

### 4.4 Übung Metall + Wasser

**a)** Nenne die Produkte der Reaktion von Cäsium mit Wasser.

- **Lösung:** Cäsiumhydroxid (\(\mathrm{CsOH}\)) und Wasserstoff (\(\mathrm{H_2}\))

**b)** Bilde die entsprechende Lauge aus dem Basismetall Lithium mit Wasser. Gib Wort- und Reaktionsgleichung an.

| Form | Gleichung |
| :--- | :--- |
| Wortgleichung | Lithium + Wasser reagiert zu Lithiumhydroxid + Wasserstoff |
| Ausgeglichen | \(2\,\mathrm{Li} + 2\,\mathrm{H_2O} \rightarrow 2\,\mathrm{LiOH} + \mathrm{H_2}\) |

**c)** Lass Kalium mit Wasser reagieren (Wort- und Reaktionsgleichung).

| Form | Gleichung |
| :--- | :--- |
| Wortgleichung | Kalium + Wasser reagiert zu Kaliumhydroxid + Wasserstoff |
| Ausgeglichen | \(2\,\mathrm{K} + 2\,\mathrm{H_2O} \rightarrow 2\,\mathrm{KOH} + \mathrm{H_2}\) |

### 4.5 Achtung – Sicherheit

Die Reaktion der Alkalimetalle mit Wasser verläuft **spontan** (keine Aktivierungsenergie nötig) und stark **exotherm** (Wärme wird freigesetzt). Der entstehende Wasserstoff ist **leicht entzündlich** und kann sich selbst entzünden. Die entstehende Lauge kann aus dem Gefäß spritzen.

**Film:** [Natrium in Wasser und Kalium in Wasser](https://www.youtube.com/watch?v=SpjxVGE_ds4)  
*(Im Wasser ist der Indikator Phenolphthalein, um die Bildung einer Lauge sichtbar zu machen.)*

## 5. Herstellung 2: Metalloxid + Wasser

### 5.1 Allgemeine Formeln

1. \(\text{Metall} + \text{Sauerstoff} \rightarrow \text{Metalloxid}\)
2. \(\text{Metalloxid} + \text{Wasser} \rightarrow \text{Metallhydroxid}\)

### 5.2 Beispiel 1: Calcium

**Schritt 1 – Oxidbildung**

| Form | Gleichung |
| :--- | :--- |
| Wortgleichung | Calcium + Sauerstoff reagiert zu Calciumoxid |
| Formel | \(\mathrm{Ca} + \mathrm{O_2} \rightarrow \mathrm{CaO}\) |
| **Ausgleichen!** | \(2\,\mathrm{Ca} + \mathrm{O_2} \rightarrow 2\,\mathrm{CaO}\) |

**Schritt 2 – Hydroxidbildung**

| Form | Gleichung |
| :--- | :--- |
| Wortgleichung | Calciumoxid + Wasser reagiert zu Calciumhydroxid |
| Formel | \(\mathrm{CaO} + \mathrm{H_2O} \rightarrow \mathrm{Ca(OH)_2}\) |

**Erklärung (Wertigkeit):** Sauerstoff hat die Wertigkeit \(-2\). Calcium steht in der 2. Hauptgruppe (Wertigkeit \(+2\)). Deshalb lautet das Oxid \(\mathrm{CaO}\) (Ladungssumme \(0\)). Sauerstoff liegt als Molekül \(\mathrm{O_2}\) vor → Gleichung ausgleichen.

### 5.3 Beispiel 2: Silber

**Schritt 1 – Oxidbildung**

| Form | Gleichung |
| :--- | :--- |
| Wortgleichung | Silber(I) + Sauerstoff reagiert zu Silber(I)oxid |
| Formel | \(\mathrm{Ag} + \mathrm{O_2} \rightarrow \mathrm{Ag_2O}\) |
| **Ausgleichen!** | \(4\,\mathrm{Ag} + \mathrm{O_2} \rightarrow 2\,\mathrm{Ag_2O}\) |

**Schritt 2 – Hydroxidbildung**

| Form | Gleichung |
| :--- | :--- |
| Wortgleichung | Silberoxid + Wasser reagiert zu Silberhydroxid |
| Formel | \(\mathrm{Ag_2O} + \mathrm{H_2O} \rightarrow \mathrm{AgOH}\) |
| **Ausgleichen!** | \(\mathrm{Ag_2O} + \mathrm{H_2O} \rightarrow 2\,\mathrm{AgOH}\) |

**Erklärung:** Silber hat die Wertigkeit \(+1\). Sauerstoff ist \(-2\), daher braucht man zwei Silber-Atome → \(\mathrm{Ag_2O}\). Zum Ausgleichen der 2 O-Atome aus \(\mathrm{O_2}\) braucht man \(2\,\mathrm{Ag_2O}\), also links \(4\,\mathrm{Ag}\).

### 5.4 Übung Metalloxid + Wasser

**a)** Bilde die entsprechende Lauge aus Eisen(II)oxid und Wasser. Gib Wort- und Reaktionsgleichung an.

| Form | Gleichung |
| :--- | :--- |
| Wortgleichung | Eisen(II)oxid + Wasser reagiert zu Eisen(II)hydroxid |
| Formel | \(\mathrm{FeO} + \mathrm{H_2O} \rightarrow \mathrm{Fe(OH)_2}\) |

**b)** Verbrenne Magnesium und lass das Produkt mit Wasser reagieren. Gib Wort- und Reaktionsgleichung an.

| Schritt | Wortgleichung | Formel |
| :--- | :--- | :--- |
| 1 | Magnesium + Sauerstoff reagiert zu Magnesiumoxid | \(2\,\mathrm{Mg} + \mathrm{O_2} \rightarrow 2\,\mathrm{MgO}\) |
| 2 | Magnesiumoxid + Wasser reagiert zu Magnesiumhydroxid | \(\mathrm{MgO} + \mathrm{H_2O} \rightarrow \mathrm{Mg(OH)_2}\) |

**c)** Bilde Aluminiumhydroxid aus dem entsprechenden Metalloxid. *(schwierig!)*

| Form | Gleichung |
| :--- | :--- |
| Wortgleichung | Aluminiumoxid + Wasser reagiert zu Aluminiumhydroxid |
| Ausgeglichen | \(\mathrm{Al_2O_3} + 3\,\mathrm{H_2O} \rightarrow 2\,\mathrm{Al(OH)_3}\) |

## 6. Indikatoren

### 6.1 Definition

Ein **Indikator** ist im chemischen Sinne ein Hilfsmittel, das dazu dient, chemische Zustände oder Reaktionen durch eine gut sichtbare Veränderung sichtbar zu machen.

### 6.2 Farbtabelle

#### Reinstoffe

| Kresolrot | gelb | gelb-orange | rot-violett |

## 7. Neutralisation

### 7.1 Definition

Reaktion, bei der eine Säure / Base mit einer Base / Säure reagiert, um sich gegenseitig aufzuheben und den **pH-Wert 7** zu erreichen.

### 7.2 Allgemeine Formel

\[
\text{Säure} + \text{Base} \rightarrow \text{Wasser} + \underbrace{\text{Säurerest} + \text{Baserest}}_{\text{Anion + Kation = Salz}}
\]

Kurz:

\[
\text{Säure} + \text{Base} \rightarrow \text{Salz} + \text{Wasser}
\]

## Übersicht – Merksätze

1. **Base** dissoziiert in Wasser zu \(\mathrm{OH^-}\) + positivem Ion → **Lauge**.
2. **Herstellung:** Alkalimetall + Wasser **oder** Metalloxid + Wasser.
3. **Indikator** macht Säure/Base/Neutral durch Farbe sichtbar.
4. **Neutralisation:** Säure + Base → Salz + Wasser (Ziel: pH 7).
5. Beim Aufstellen von Gleichungen immer **Atome zählen und ausgleichen**.
