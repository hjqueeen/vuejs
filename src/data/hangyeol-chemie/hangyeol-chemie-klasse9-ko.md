## 1. 염기 – 정의와 해리

**날짜:** 2024.11.11 · **자료:** Basen – Informationsblatt / Übungen

### 1.1 정의

염기는 수용액에서 음전하를 띤 **수산화 이온(\(OH^-\))**과 양전하를 띤 이온(대개 금속 이온)으로 분해되는 물질이다. 이 과정을 **염기의 해리(Dissoziation)**라고 한다. 생기는 용액을 **알칼리성 용액** 또는 **수용액(Lauge)**이라고 한다.

### 1.2 일반식

\[
\text{염기} + \text{물} \rightarrow \text{염기 잔기 이온} + \text{수산화 이온} + \text{물}
\]

**예 – 수산화나트륨:**

| 형태 | 식 |
| :--- | :--- |
| 단어식 | Natriumhydroxid + Wasser → Natrium-Ion + Hydroxid-Ion + Wasser |
| 화학식 | \(\mathrm{NaOH} + \mathrm{H_2O} \rightarrow \mathrm{Na^+} + \mathrm{OH^-} + \mathrm{H_2O}\) |
| 짧게 | \(\mathrm{NaOH} \xrightarrow{\mathrm{H_2O}} \mathrm{Na^+} + \mathrm{OH^-}\) |

### 1.3 전하와 이온 규칙

- 염기 잔기 이온의 **양전하**는 주기율표 **주기(Hauptgruppe) 번호**와 같다.
- **수산화 이온의 개수**는 그 양전하와 같다.
- 표기: \((\mathrm{OH})_x\)가 맞음 (\(x\)개의 O·H); \(\mathrm{OH}_x\)는 틀림 (H만 \(x\)개로 읽힘).
- **전이금속(Nebengruppe) 예외:** 전하는 괄호 안 **로마 숫자**로 표시.

**예시:**

| 물질 | 해리식 |
| :--- | :--- |
| 수산화칼슘 (2족) | \(\mathrm{Ca(OH)_2} \rightarrow \mathrm{Ca^{2+}} + 2\,\mathrm{OH^-}\) |
| 수산화철(III) | \(\mathrm{Fe(OH)_3} \rightarrow \mathrm{Fe^{3+}} + 3\,\mathrm{OH^-}\) |

### 1.4 연습 – 해리

**a)** 수산화알루미늄

\[
\mathrm{Al(OH)_3} \rightarrow \mathrm{Al^{3+}} + 3\,\mathrm{OH^-}
\]

**b)** 수산화니켈(II)

\[
\mathrm{Ni(OH)_2} \rightarrow \mathrm{Ni^{2+}} + 2\,\mathrm{OH^-}
\]

## 4. 제조법 1: 금속 + 물

### 4.1 일반식

염기 금속(1족 / 알칼리 금속) + 물:

\[
\text{금속} + \text{물} \rightarrow \text{금속수산화물} + \text{수소 (기체)}
\]

### 4.2 예: 나트륨 + 물

| 형태 | 식 |
| :--- | :--- |
| 단어식 | Natrium + Wasser → Natriumhydroxid + Wasserstoff |
| 화학식 (미균형) | \(\mathrm{Na} + \mathrm{H_2O} \rightarrow \mathrm{NaOH} + \mathrm{H_2}\) |
| **균형 맞추기!** | \(2\,\mathrm{Na} + 2\,\mathrm{H_2O} \rightarrow 2\,\mathrm{NaOH} + \mathrm{H_2}\) |

### 4.3 균형을 맞추는 이유

- 수소(\(H_2\))는 실온에서 기체이고 비활성기체가 아니므로 분자로 쓴다.
- 왼쪽 \(\mathrm{H_2O}\)의 H는 2개, 오른쪽은 \(\mathrm{NaOH}\) 1개 + \(\mathrm{H_2}\) 2개 = 3개 → 맞지 않음.
- \(2\,\mathrm{H_2O}\)로 하면 \(2\,\mathrm{NaOH}\)가 생기고, 그에 맞춰 왼쪽도 \(2\,\mathrm{Na}\)가 필요.

### 4.4 연습: 금속 + 물

**a)** 세슘과 물의 반응 생성물을 쓰시오.

- **풀이:** 수산화세슘(\(\mathrm{CsOH}\))과 수소(\(\mathrm{H_2}\))

**b)** 리튬과 물로 해당 수용액(Lauge)을 만드시오. 단어식과 반응식을 쓰시오.

| 형태 | 식 |
| :--- | :--- |
| 단어식 | Lithium + Wasser → Lithiumhydroxid + Wasserstoff |
| 균형식 | \(2\,\mathrm{Li} + 2\,\mathrm{H_2O} \rightarrow 2\,\mathrm{LiOH} + \mathrm{H_2}\) |

**c)** 칼륨을 물과 반응시키시오 (단어식·반응식).

| 형태 | 식 |
| :--- | :--- |
| 단어식 | Kalium + Wasser → Kaliumhydroxid + Wasserstoff |
| 균형식 | \(2\,\mathrm{K} + 2\,\mathrm{H_2O} \rightarrow 2\,\mathrm{KOH} + \mathrm{H_2}\) |

### 4.5 주의 – 안전

알칼리 금속과 물의 반응은 **자발적**(활성화 에너지 불필요)이고 강하게 **발열적(exotherm)**이다. 생기는 수소는 **쉽게 연소**하며 스스로 불을 붙일 수 있다. 생긴 수용액이 용기 밖으로 튀을 수 있다.

**영상:** [Natrium in Wasser und Kalium in Wasser](https://www.youtube.com/watch?v=SpjxVGE_ds4)  
*(물에 페놀프탈레인을 넣어 수용액 생성을 보이게 함.)*

## 5. 제조법 2: 금속산화물 + 물

### 5.1 일반식

1. \(\text{금속} + \text{산소} \rightarrow \text{금속산화물}\)
2. \(\text{금속산화물} + \text{물} \rightarrow \text{금속수산화물}\)

### 5.2 예 1: 칼슘

**1단계 – 산화물 생성**

| 형태 | 식 |
| :--- | :--- |
| 단어식 | Calcium + Sauerstoff → Calciumoxid |
| 화학식 | \(\mathrm{Ca} + \mathrm{O_2} \rightarrow \mathrm{CaO}\) |
| **균형!** | \(2\,\mathrm{Ca} + \mathrm{O_2} \rightarrow 2\,\mathrm{CaO}\) |

**2단계 – 수산화물 생성**

| 형태 | 식 |
| :--- | :--- |
| 단어식 | Calciumoxid + Wasser → Calciumhydroxid |
| 화학식 | \(\mathrm{CaO} + \mathrm{H_2O} \rightarrow \mathrm{Ca(OH)_2}\) |

**설명(원자가):** 산소 원자가 \(-2\), 칼슘은 2족(\(+2\)). 그래서 산화물은 \(\mathrm{CaO}\)(전하 합 0). 산소는 \(\mathrm{O_2}\) 분자로 존재 → 식 균형 필요.

### 5.3 예 2: 은

**1단계 – 산화물 생성**

| 형태 | 식 |
| :--- | :--- |
| 단어식 | Silber(I) + Sauerstoff → Silber(I)oxid |
| 화학식 | \(\mathrm{Ag} + \mathrm{O_2} \rightarrow \mathrm{Ag_2O}\) |
| **균형!** | \(4\,\mathrm{Ag} + \mathrm{O_2} \rightarrow 2\,\mathrm{Ag_2O}\) |

**2단계 – 수산화물 생성**

| 형태 | 식 |
| :--- | :--- |
| 단어식 | Silberoxid + Wasser → Silberhydroxid |
| 화학식 | \(\mathrm{Ag_2O} + \mathrm{H_2O} \rightarrow \mathrm{AgOH}\) |
| **균형!** | \(\mathrm{Ag_2O} + \mathrm{H_2O} \rightarrow 2\,\mathrm{AgOH}\) |

**설명:** 은의 원자가는 \(+1\). 산소가 \(-2\)이므로 은 원자 2개 필요 → \(\mathrm{Ag_2O}\). \(\mathrm{O_2}\)의 O 2개를 맞추려면 \(2\,\mathrm{Ag_2O}\), 따라서 왼쪽은 \(4\,\mathrm{Ag}\).

### 5.4 연습: 금속산화물 + 물

**a)** 산화철(II)과 물로 해당 수용액을 만드시오.

| 형태 | 식 |
| :--- | :--- |
| 단어식 | Eisen(II)oxid + Wasser → Eisen(II)hydroxid |
| 화학식 | \(\mathrm{FeO} + \mathrm{H_2O} \rightarrow \mathrm{Fe(OH)_2}\) |

**b)** 마그네슘을 태운 뒤 생성물을 물과 반응시키시오.

| 단계 | 단어식 | 화학식 |
| :--- | :--- | :--- |
| 1 | Magnesium + Sauerstoff → Magnesiumoxid | \(2\,\mathrm{Mg} + \mathrm{O_2} \rightarrow 2\,\mathrm{MgO}\) |
| 2 | Magnesiumoxid + Wasser → Magnesiumhydroxid | \(\mathrm{MgO} + \mathrm{H_2O} \rightarrow \mathrm{Mg(OH)_2}\) |

**c)** 해당 금속산화물로 수산화알루미늄을 만드시오. *(어려움!)*

| 형태 | 식 |
| :--- | :--- |
| 단어식 | Aluminiumoxid + Wasser → Aluminiumhydroxid |
| 균형식 | \(\mathrm{Al_2O_3} + 3\,\mathrm{H_2O} \rightarrow 2\,\mathrm{Al(OH)_3}\) |

## 6. 지시약

### 6.1 정의

**지시약(Indikator)**은 화학적으로 상태나 반응을 **눈에 잘 띄는 변화**로 보이게 하는 보조 수단이다.

### 6.2 색 표

#### 순물질(Reinstoffe)

| 지시약 | 산성 용액 | 중성 용액 | 염기성 용액 |
| :--- | :--- | :--- | :--- |
| Methylrot (메틸레드) | 빨강 | 노랑 | 노랑 |
| Kresolrot (크레졸레드) | 노랑 | 노랑-주황 | 빨강-보라 |
| Phenolphthalein (페놀프탈레인) | 무색 | 무색 | 분홍 |

#### 혼합물(Stoffgemische)

| 지시약 | 산성 용액 | 중성 용액 | 염기성 용액 |
| :--- | :--- | :--- | :--- |
| Lackmus (리트머스) | 빨강 | 보라 | 파랑 |
| Universalindikator (만능지시약) | 빨강 → 노랑 | 초록 | 파랑 → 보라 |
| Rotkohlsaft (적양배추즙) | 빨강-분홍 | 보라 | 파랑 / 초록 |

## 7. 중화

### 7.1 정의

산 / 염기가 염기 / 산과 반응하여 서로를 상쇄하고 **pH 7**에 이르게 하는 반응.

### 7.2 일반식

\[
\text{산} + \text{염기} \rightarrow \text{물} + \underbrace{\text{산 잔기} + \text{염기 잔기}}_{\text{음이온 + 양이온 = 염(Salz)}}
\]

짧게:

\[
\text{산} + \text{염기} \rightarrow \text{염} + \text{물}
\]

## 요약 – 암기 포인트

1. **염기**는 물에서 \(\mathrm{OH^-}\) + 양이온으로 해리 → **알칼리성 용액(Lauge)**.
2. **제조:** 알칼리 금속 + 물 **또는** 금속산화물 + 물.
3. **지시약**은 산/염기/중성을 색으로 보여 준다.
4. **중화:** 산 + 염기 → 염 + 물 (목표 pH 7).
5. 반응식을 세울 때는 항상 **원자 수를 세어 균형을 맞춘다**.
